# Four-week plan
| Week | Shared outcome |
| --- | --- |
| 1 | Agree on interfaces and dependencies; each component has a tiny example; connect a mocked request-to-proposal path |
| 2 | Real request → agent → MCP → retrieval/pricing → draft PDF; integrate before the end of the week |
| 3 | Approval, test delivery, persistent follow-up and failure handling; add integration tests |
| 4 | Fix bugs, validate real-model examples, polish UI/PDF, rehearse and document the demo |

Have two short integration sessions each week. Merge small PRs as soon as reviewed.
Choose one fictional company and one service domain. Use synthetic customer data only.
